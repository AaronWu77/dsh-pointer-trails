# 指针轨迹

[English](README.md) | 中文

## 概述

可穿透点击的画布在 Web 客户端后方绘制柔和光带。指针位于图层内时光带跟随指针，离开后自主漂移。插件不拦截输入，也不修改会话。

## 组合方式

[组合补丁](cordis.patch.yml)挂载无操作的 Host 入口；manifest 声明 Web 客户端入口。此组合需要 Host 入口，它不是无效代码。插件不提供运行时配置，也不保存数据。

## 动画与生命周期

客户端通过 Cordis effect 注册画布。卸载会取消动画、移除监听器、断开尺寸观察器并移除图层。文档隐藏时跳过绘制。减少动态效果偏好在挂载时读取：启用时只绘制一帧，不启动动画循环。

## 开发

构建输出带类型声明的 ESM Host 模块及 Harness 模块加载器使用的浏览器工厂。画布不使用样式表，因此构建不需要 CSS 或 Tailwind 编译器。构建仍检查共享浏览器模块。

## 模型影响

插件不注册工具，也不添加模型上下文。不消耗模型 token，不宣称改善 KV 缓存。

## 已知限制

插件面向本地固定宿主集成，没有跨版本兼容矩阵或自动化视觉验收测试。更改减少动态效果偏好后，需要重新挂载客户端入口。动画参数不可由用户配置。
